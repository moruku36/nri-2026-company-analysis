# 取締役会・諮問委員会の活動分析

基準日: 2026-09-20

## Executive take

NRIは2026年時点で、監査等委員会設置会社を採用し、業務執行の権限を執行側へ委譲しつつ、取締役会を全社レベルの重要意思決定と監督に集中させる設計としている。

2026年版統合レポートの特徴は、制度だけでなく、**取締役会と諮問委員会が1年間に何を審議したか**を比較的具体的に開示している点にある。

## 1. 取締役会の構成

### Fact

2026年6月19日時点の取締役は13名。

- 監査等委員でない取締役: 8名（うち社外3名）
- 監査等委員である取締役: 5名（うち社外3名）
- 独立社外取締役: 6名
- 取締役会議長: 非業務執行の取締役会長

NRIは取締役の3分の1以上を独立社外取締役とする方針を開示している。

取締役会のスキル構成では、経営戦略上の期待として「イノベーション」「グローバル」「人材」を置き、専門領域として「企業経営」「事業」「ガバナンス・リスク管理」「財務・会計・M&A」「環境・社会」を整理している。

### Interpretation

2026年は海外事業の再構築とAI/AX転換を同時に進めるため、取締役会に求められる能力は従来の国内SI事業監督だけでは足りない。

特に、グローバル事業、M&A、リスク管理の知見を明示的にスキルマトリクスへ組み込んでいる点は、海外事業の課題を踏まえた監督能力の重要性を会社側も認識していることを示す。

## 2. 2026年3月期の取締役会活動

### Fact

2026年3月期の取締役会は14回開催された。

主な審議・検討内容は以下。

| 分類 | 主な審議・検討内容 |
|---|---|
| 経営・事業戦略 | 中期経営計画、事業計画、グローバル戦略、グループ会社再編、買収・出資、人的資本・人材戦略、出資先の状況 |
| 役員人事・報酬 | 役員人事、役員報酬、諮問委員会報告 |
| 財務・IR | 財務戦略、年次・四半期決算、月次業績、資金・財務、配当方針、IR状況 |
| ガバナンス・リスク | 機関設計変更、取締役会実効性評価、リスク管理、情報セキュリティ、グループガバナンス |
| 監査 | 監査等委員会監査、内部監査 |
| 執行監督 | 四半期業務執行状況、経営会議の主な付議案件 |

### Interpretation

公開資料上、海外・M&A・出資・グループ会社再編は取締役会レベルの議題として明示されている。

したがって投資家が今後見るべきなのは「取締役会で扱っているか」ではなく、**どのタイミングで、どの深さで、悪化兆候を含む情報が上がり、議論・意思決定に反映されたか**である。

## 3. 指名諮問委員会

### Fact

指名諮問委員会は、社長の後継者計画、取締役候補者、社長等の選定の妥当性を審議する取締役会の任意の諮問機関。

2026年6月19日時点では6名中4名が独立社外取締役で、委員長は独立社外取締役の小堀秀毅氏。

2025年度は3回開催された。

2026年3月期の主な審議内容は、

- 取締役会の構成
- 社外取締役の独立性基準の明確化
- 知見・経験・専門性・実績等から見た取締役候補者
- 翌期業務執行体制に基づく執行役員・経営役等の選定・配置

など。

また、若手経営層から次世代経営チームを形成し、その中から社長後継者を選ぶプロセスを基本としている。

### Interpretation

後継者選定を現CEO個人の指名ではなく、次期経営チーム形成とセットで扱っている点は、経営継承の連続性を重視した設計。

2026年度から委員長を独立社外取締役とした点は、指名プロセスの独立性を一段強める変更と読める。

## 4. 報酬諮問委員会

### Fact

報酬諮問委員会は、取締役報酬の体系・水準・個人別報酬等を審議する任意の諮問機関。

2026年6月19日時点では6名中4名が独立社外取締役。ただし委員長は代表取締役 専務執行役員の山﨑政明氏。

2025年度は3回開催された。

2026年3月期は、

- 基本報酬・賞与・株式関連報酬
- 役員報酬水準の検証
- 中期経営計画（2026-2028）以降の役員報酬制度

を主に審議した。

監査等委員でない社内取締役の賞与には営業利益、親会社所有者帰属利益、ROEが反映される。株式関連報酬にはサステナビリティ評価を考慮する仕組みがあり、財務諸表の訂正等に対応するクローバック制度、非違行為に対応するマルス条項もある。

### Watch

2026年3月期の取締役会実効性評価では、指名諮問委員会に続き、報酬諮問委員会についても**社外取締役を委員長とすることの検討**が期待されると記載された。

独立社外取締役が過半数を占めることと、委員長を誰が務めるかは別の論点であり、2027年3月期の変更有無は確認対象となる。

## 5. サステナビリティ・ガバナンス委員会と執行側会議体

サステナビリティ・ガバナンス委員会は、サステナビリティ経営の枠組みやマテリアリティを取締役レベルで審議する。

執行側には、経営会議のほか、統合リスク管理会議、コンプライアンス会議、サステナビリティ会議、人材開発会議、事業開発会議、システム開発会議、情報開示会議、危機管理会議、業務推進委員会等が置かれている。

このうち投資家目線で特に重要なのは、

- 統合リスク管理会議: システム障害、情報セキュリティ、事業継続等
- 事業開発会議: 研究開発、企画事業、有価証券取得等の投資
- システム開発会議: 大型IT案件の提案・見積もり・開発・リリース
- 情報開示会議: 有価証券報告書等の開示

である。
