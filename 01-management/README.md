基準日: 2026-09-15

このディレクトリでは、2026年のNRIを「経営陣が何を言っているか」だけでなく、**数値目標・資本配分・実行施策と整合しているか**まで見ていく。

## 結論を3行で

- NRIの2026-2028中計は、従来のDX延長ではなく **AX（AI Transformation）を次の成長エンジンに置く計画**。
- 同時に、海外の規模拡大路線を修正し、**国内高収益事業 + AI/セキュリティ投資 + 海外事業の再構築**へ軸足を移している。
- AIは売上拡大だけでなく、NRI自身の開発生産性・人員配置・収益モデルを変える手段として扱われており、SIerとしての自己変革まで計画に含まれる。
