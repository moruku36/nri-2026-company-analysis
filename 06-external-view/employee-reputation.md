# Employee Reputation — 社員・元社員口コミから見るNRI

基準日: 2026-09-25

## Executive take

公開口コミから見えるNRIは、**高待遇・成長機会・法令順守への評価が高い一方、仕事量と長時間労働の重さが継続的な弱点**という姿。

ただし、口コミサイトは回答者の自己選択バイアスが強く、部署・職種・上司・案件で体験差も大きい。数字は会社全体の客観評価ではなく、外部から見える「評判の傾向」として読む。

---

## 1. OpenWorkの公開スナップショット

公開検索で確認できる比較ページでは、NRIは概ね以下。

| 項目 | 公開値 |
|---|---:|
| 総合評価 | 4.38 / 5 |
| 待遇面の満足度 | 4.5 |
| 社員の士気 | 3.8 |
| 風通しの良さ | 3.9 |
| 社員の相互尊重 | 3.9 |
| 20代成長環境 | 4.5 |
| 人材の長期育成 | 4.0 |
| 法令順守意識 | 4.4 |
| 人事評価の適正感 | 3.7 |
| 残業時間 | 約45.1時間/月 |
| 有給休暇消化率 | 約56.4% |

口コミ件数は7,000件超と大きい。

### Interpretation

外部から見た強みは明確。

- 給与
- 若手の成長機会
- 教育
- コンプライアンス
- 社員同士の質

一方、総合評価が高くても、残業時間は軽くない。

「高待遇の代わりに高い成果要求がある会社」という認識が形成されやすい。

---

## 2. エン カイシャの評判

エンゲージ/カイシャの評判の公開比較スナップショットでは、NRIは

- 総合評価 3.7
- 会社の成長性・将来性 4.0
- 20代成長環境 4.0
- 仕事を通じた社会貢献 3.7
- 経営陣の手腕 3.6

など比較的高い評価。

一方、公開比較では残業時間が50時間前後と表示されるケースもある。

### 注意

OpenWorkと数値が違うのは、

- 回答者層
- 集計期間
- 算出方法
- 更新タイミング

が異なるため。

絶対値より「高待遇・成長性は高評価、労働時間は重い」という共通傾向を見るべき。

---

## 3. 評判上のStrong points

### 高待遇

NRIの平均給与水準は国内IT/SIerの中では非常に高く、口コミでも待遇満足度が高い。

### 若手成長環境

若手でも顧客との直接対話、大規模案件、PM/設計、コンサル的な仕事を任されやすいという評価が多い。

### 人材育成

研修・資格支援・OJT・専門キャリアなど、育成インフラに対する評価は高め。

### ブランド/転職市場価値

NRI経験が、

- コンサル
- 大手事業会社
- IT企業
- 金融

へのキャリアオプションにつながるという認識が広い。

---

## 4. 評判上のWeak points

### 長時間労働

公開集計では月40〜50時間台の残業が見える。

会社制度としての働き方改善と、現場プロジェクトの負荷は別問題。

### プロジェクト依存

同じ会社でも、

- 部署
- 顧客
- 案件フェーズ
- 上司

で体験が大きく変わるという口コミ傾向がある。

### 高い期待値

高給与・高単価人材として、若手から顧客対応とアウトプット品質を求められる。

### 評価制度

待遇満足度ほど「評価の適正感」は高くない。役割・昇進・評価の納得感は改善余地として残る。

---

## 5. AI時代に口コミ評価はどう変わるか

NRIはAIで開発工数を削減し、余力を高付加価値業務へ移す方針。

これが本当に実現すると、社員側では

### Positive scenario

- 単純作業減少
- 開発/資料作成時間短縮
- 高付加価値業務へ集中
- 長時間労働改善

### Negative scenario

- AIで効率化した分だけ担当案件が増える
- 成果期待がさらに高くなる
- 「AIを使えること」が前提能力になる
- 余力が労働時間削減ではなく売上拡大へ吸収される

という両方があり得る。

**AI生産性向上が社員のQOL改善までつながるかは、外部評価上も重要な観測点。**

## Methodological caution

口コミデータは個人の主観であり、会社の全社員を代表しない。特に残業・評価・人間関係は部門差が大きいため、本レポートでは傾向把握に限定して利用する。
