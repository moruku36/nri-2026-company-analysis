# 04. Governance / コーポレート・ガバナンス分析

基準日: 2026-09-20

このディレクトリでは、NRIのコーポレート・ガバナンスを制度の有無だけでなく、**取締役会で実際に何が議論され、会社自身がどこを課題と認識しているか**という観点から確認する。

## Executive take

2026年のNRIは、監査等委員会設置会社への移行、社外取締役比率の向上、指名諮問委員会の社外取締役委員長化など、ガバナンス体制の形式面を強化している。

一方、2026年3月期の取締役会実効性評価では、取締役会の実効性は「概ね確保」としつつも、**重要議題の審議の深さ、グローバル戦略、グループ会社リスクの早期報告、中長期的なリスク議論**に改善余地があると自ら開示している。

投資家にとって重要なのは、委員会の設置数ではなく、2026年3月期に発生した海外事業の大規模減損を踏まえ、今後のグローバル事業・M&A・グループ会社管理について、取締役会がどれだけ早く異変を把握し、長期戦略まで踏み込んで監督できるかである。

> 注意: 公開資料は、海外減損の発生原因を「取締役会への報告遅延」や「ガバナンス不全」と直接結び付けてはいない。本章では、減損と実効性評価の課題を同一原因として断定せず、**同時期に投資家が確認すべきガバナンス論点**として並べて分析する。

## この章の重要な発見

### 1. 「委員会がある」だけでなく、具体的な審議内容まで開示している

2026年版統合レポートでは、取締役会が中期経営計画、グローバル戦略、グループ会社再編、買収・出資、人的資本、財務戦略、IR、リスク管理、情報セキュリティ、グループガバナンス等を審議したことを明示している。

指名諮問委員会では取締役会構成、独立性基準、役員候補者、翌期の業務執行体制等を、報酬諮問委員会では基本報酬・賞与・株式報酬、中計2028以降の役員報酬制度等を検討した。

### 2. 会社自身がグローバル戦略・グループガバナンスの改善余地を認めている

実効性評価では、グローバル戦略について定期報告だけでなく適時適切な報告と長期視点の継続審議が必要とされた。

また、グループ会社のリスクや懸念点に関する取締役会への報告が遅延していたとして、より早期の報告が期待されると明記されている。

### 3. 社外取締役のコメントは海外事業の監督課題をかなり率直に示している

統合レポート2026のガバナンス鼎談では、社外取締役から、グローバル事業について将来戦略の議論が当初から十分に深められなかったことや、もっと早い段階で現実を深く直視して議論すべきだったとの発言が掲載されている。

これは海外減損の原因認定ではないが、NRI自身の統合レポートでここまで踏み込んだ振り返りが出ている点は、今後の監督改善を追う上で重要である。

### 4. 報酬設計は利益・資本効率・中長期価値を意識

監査等委員でない社内取締役の賞与には営業利益、親会社所有者帰属利益、ROEを反映する。株式関連報酬にはサステナビリティ評価を考慮する仕組みがあり、クローバック制度とマルス条項も導入されている。

## Investor watch

- グローバル事業について取締役会へ報告する頻度・内容が具体化されるか
- 豪州・北米の再建で追加減損や新たな重大リスクが発生しないか
- M&A・出資案件の事後評価や撤退基準の開示が深まるか
- グループ会社のリスク・懸念点が「早期報告」へ改善したか
- 取締役会実効性評価で2026年度の改善が確認できるか
- 報酬諮問委員会の委員長を独立社外取締役とするか
- AI・サイバー・地政学リスクがインシデント報告ではなく、中長期の予兆管理として議論されるか
