# AI Strategy Watchlist

基準日: 2026-09-25

このファイルは、今後の決算・ニュースでNRIのAI戦略が本当に進んでいるかを判定するための観測項目をまとめる。

## 売上・案件

- AI関連売上の進捗（2028年度3,000億円以上目標）
- AIコンサル案件数
- AFT案件数 / 顧客業界
- FDEの人数・配置
- AIエージェントの本番導入件数
- モダナイゼーション案件との連鎖

## 生産性

- AI駆動開発の適用率
- Claude Code等の開発ツール利用率
- 工数削減率
- 開発リードタイム
- 品質 / 障害指標
- 外注費・パートナー人数

## モデル / パートナー

- Claude Fable 5.1 / Opus 5等への移行
- GPT-6 Astra採用事例
- OpenAIとの公式協業の有無
- Google / Gemini系の採用拡大
- 業界・タスク特化LLMの商用展開
- モデル評価・切替基盤の標準化

## エージェント

- Claude Coworkの社内本番利用
- OpenAI Agents API等の採用
- マルチエージェント構成
- エージェント権限管理
- Human-in-the-loop設計
- 業務プロセス単位の自律化

## セキュリティ / ガバナンス

- AgenticBlueの外販・横展開
- AIレッドチーミング
- AIエージェント監視
- AIインシデント対応
- 規制対応
- AIによるサイバー攻撃への防御サービス

## 経営・人材

- AI投資800億円の使途
- AI人材育成数
- 職種 / 評価制度の変化
- 人員計画へのAI生産性の反映
- 人月型からアウトカム型への売上構成変化

## 判定のポイント

NRIのAI戦略が成功していると言えるのは、単にAI関連ニュースが増えたときではない。

以下の3つが同時に確認できたとき。

1. **顧客売上が増える** — AI / AX案件が大型・継続案件へ育つ
2. **内部原価が下がる** — AI駆動開発が利益率へ継続的に効く
3. **売上モデルが変わる** — 工数削減で売上を失わず、アウトカム・サービス型へ転換できる

この3点を四半期ごとに追跡する。
