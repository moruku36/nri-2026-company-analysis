# 07. People / Work / Career Implications

> 基準日: 2026-09-15  
> **Public-safe:** この章は公開情報だけを使い、個人の健康・家庭・社内事情・顧客情報・非公開プロジェクト・人事情報等を含めない。

このディレクトリでは、2026年のNRIの人材戦略とAI/AX戦略から、**NRIで働くエンジニアやPMの仕事がどう変わり、どの能力の価値が上がるか**を分析する。

個人向けの示唆を含むが、公開リポジトリであるため、特定個人の事情ではなく「クラウド / セキュリティ / PM / アーキテクチャに関心を持つ技術者」という一般化した読者像を前提にする。

## 結論を先に

### 1. NRIは「人数を増やす」より「人の配置を上へ動かす」方向

中期経営計画では、AIを使った生産革新と並び、

- AI / セキュリティ高度専門人材へのアップスキリング
- 外部獲得の強化
- 開発人材の上流シフト

を明示している。

2025年度実績から2028年度計画では、

| 人材KPI | 2025実績 | 2028計画 |
|---|---:|---:|
| AI高度人材 | 1,147名 | 3,000名 |
| セキュリティ高度人材 | 1,198名 | 2,000名 |
| 従業員エンゲージメント総合スコア | 73 | 70以上を継続 |

AI高度人材は約2.6倍、セキュリティ高度人材は約1.7倍にする計画である。

### 2. コーディング / テスト中心の価値から、設計 / 判断 / 顧客変革へ重心が移る

2026年5月の機関投資家向けQ&AでNRI経営陣は、AI駆動開発により下流工程の工数が減る場合、社員を営業・コンサルティング等の上流へ移す考えを示した。

NRIは自社社員について、企画・提案から設計・開発までを担当できる多能工型を強みとしており、上流へのシフトは比較的進めやすいとの認識を示している。

### 3. 「AIが使える」だけでは高度人材にならない

NRIが公表しているAX戦略を見ると、価値の中心は

- 顧客業務の理解
- 変革構想
- AI / クラウド / 既存システムの統合設計
- セキュリティ / ガバナンス
- ROIの説明
- 本番運用

へ移っている。

プロンプト作成や単純な生成AI利用はベーススキル化し、**業務・技術・責任をつなげられる人材**の希少性が上がると考える。

### 4. クラウド / セキュリティ / PMはAIに置き換わるより「AIを内包する」

AI時代にもクラウド、セキュリティ、PMが不要になるわけではない。

むしろ、

- Cloud Architecture × AI Platform
- Security × AI Governance / Agent Security
- PM × AI Delivery / ROI / Outcome
- Architecture × Modernization × AI

のように既存専門性へAIを組み込む役割が重要になる。

### 5. 最も避けたいのは「調整だけ」「手作業だけ」の役割に固定されること

AIによる代替圧力が高いのは、

- 定型資料の作成
- 定型調査
- 単純コーディング
- 単純テスト
- 手順化された運用
- 情報の中継だけを行うPMO

など。

人間側は **課題設定・設計・意思決定・説明責任・顧客コンテキスト**へ寄る必要がある。

## この章の読み方

この章は会社の人事制度や昇進制度を予測するものではない。

公開された経営計画・IR・NRI自身の研究・サービス戦略から、仕事の価値配分がどの方向へ動きそうかを分析する。

したがって、

- **Fact**: NRIが公開した人材KPI・方針
- **Management view**: 経営陣が説明している配置 / 育成方針
- **NRI research**: NRIの研究者・コンサルタントが顧客企業向けに提示する考え
- **Interpretation**: 本レポートによるキャリア上の読み取り

を区別する。
