# Public Reputation — 一般公開情報上のNRIイメージ

基準日: 2026-09-25

## Executive take

一般公開の転職記事、就活記事、個人投資家記事、掲示板/SNS系の言及を眺めると、NRIの外部イメージはかなり一貫している。

**「高給・高学歴・成長できる・金融/ITに強い・入社難易度が高い。その代わり忙しい」**という像。

2026年にNRIが強く打ち出すAX/Agentic AIは、一般層の企業イメージをまだ完全には上書きしていない。

---

## 1. 最も強い一般イメージは「高待遇のコンサル×IT」

転職・就活系の記事ではNRIを、

- シンクタンク
- コンサル
- 金融系SIer
- 高年収
- 難関企業

として説明するケースが多い。

AI企業として語られるよりも、既存の「コンサルとITの二刀流」ブランドの方が一般認知として強い。

### Interpretation

AXを会社の新しい看板にしたいなら、AFTやAI Agentの成功事例が一般メディアや転職市場まで浸透する必要がある。

---

## 2. 「辞めても市場価値が高い」という評判

2026年9月の転職関連記事では、NRI出身者の転職先として、

- Accenture等のコンサル
- 通信
- メーカー
- 商社
- Web/IT企業

などが紹介されている。

個別記事なので厳密な転職統計ではないが、一般認識として

> NRI経験は他社でも評価される

というブランドが形成されている。

---

## 3. 忙しさはブランドの裏面として認識される

口コミ、転職記事、就活コンテンツでは、高待遇とセットで

- 長時間労働
- 高い成果要求
- 顧客都合
- プロジェクト依存

が語られやすい。

### Interpretation

NRIに対する一般評価は「ブラック企業」という単純な否定ではなく、

> 忙しいが、それに見合う給与・成長機会がある

という交換条件型の理解に近い。

AIによってこの交換条件が変わるかは今後の注目点。

---

## 4. 海外では知名度差がある

英語圏の一般的なキャリア掲示板では、NRIの認知度はAccenture、Deloitte、IBM等より低い。

2026年のReddit上の一投稿では、NRIについて「日本では大手だが東南アジアでの影響は相対的に小さい」という趣旨の認識が示されている。

### Caution

これは単独投稿であり、地域全体のブランド調査ではない。

ただし、国内での圧倒的な就職人気と比較すると、海外ブランドにギャップがあるという仮説とは整合する。

---

## 5. AIに関する一般イメージはまだ形成途中

2026年にNRIは、

- AX
- AFT
- AI Agent
- Claude Enterprise
- AgenticBlue

等を強く打ち出している。

しかし一般向け記事の主題は依然として、

- 年収
- 転職
- 就職難易度
- コンサル
- 金融IT

が中心。

### Interpretation

「NRI = AI Transformation」というブランドは経営・IR層では形成され始めたが、一般認知への浸透はこれから。

---

## 6. Public narrative map

```text
従来のNRIイメージ
高学歴 / 高給 / 金融 / SI / コンサル / 激務
                ↓
2026年に会社が追加したいイメージ
AX / Agent / FDE / AI Security / AI-native delivery
                ↓
今後必要なもの
顧客成功事例 / 社員の働き方変化 / 外部開発者の利用 / 海外実績
```

## 7. 評価

一般評判という観点では、NRIには大きなブランド毀損は見られず、むしろ非常に強い。

ただし強さの源泉はまだ主に、**給与・学歴ブランド・金融IT・コンサル・安定性**。

AXを次の企業ブランドにするには、技術発表よりも「実際に何が変わったか」を一般にも理解できる成果へ翻訳する必要がある。
