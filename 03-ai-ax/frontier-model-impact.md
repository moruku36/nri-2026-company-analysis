# Frontier Model Impact — 2026年8〜9月

基準日: 2026-09-15

## Executive take

2026年8〜9月は、NRIのAI戦略を評価するうえで重要な転換点になった。

Anthropicは9月1日にClaude Fable 5.1 / Mythos 5.1、OpenAIは9月3日にGPT-6 Astra、9月10日にAgents APIを発表した。さらにOpenAIは8月にGPT-5.6系を更新している。

しかし、9月15日時点でNRIがこれら**個別の最新モデル名を受けて全社AI戦略を変更したと示す公式発表は確認できていない**。

これは必ずしも出遅れではない。

NRIの公開戦略を見る限り、モデル更新のたびに方針転換するのではなく、

> **複数モデルを継続評価し、顧客業務に最適なものを選び、企業システムとして安全に実装する**

ことを自社価値としている。

## 2. NRIはGPT-6 Astraに公式反応したか

### Finding

9月15日時点で、NRI公式サイト・ニュースリリース・NRI AIの公開情報を検索した範囲では、GPT-6 Astraを名指しした新たな全社戦略発表は確認できなかった。

### Interpretation

NRIはOpenAIの最新モデルを無視している、と読むべきではない。

NRIは以前から、標準ベンチマークだけでなく**実際の日本企業の業務タスクに基づいてモデルを比較評価する**アプローチを取っている。

したがって、GPT-6 Astraについても、

- 日本語業務性能
- コーディング
- セキュリティ
- コスト
- レイテンシ
- データ管理
- エンタープライズ統制

を評価した上で案件ごとに採否を決める方が、NRIの既存方針と整合する。

## 3. Anthropic新モデルの影響はOpenAIより直接的

NRIは2026年2月にAnthropic Japanとのパートナーシップを拡大し、

- Claude for Enterpriseの社内導入
- Claude Code
- Claude Cowork検証
- AWS / Bedrock経由の提供
- 日本企業向け導入支援

まで進めている。

このためFable 5.1等の能力向上は、NRI社内の生産性と顧客向けサービスの双方へ比較的直接反映される可能性が高い。

ただし、9月15日時点ではNRI自身からFable 5.1 / Mythos 5.1を名指しした新発表は確認できていない。

## 4. 最新モデルほどNRIの「統合レイヤー」は不要になるのか

### Bear case

フロンティアAIが進化すると、

- コード生成
- システム設計
- データ分析
- 業務自動化
- エージェント構築

がベンダー製品だけで完結しやすくなる。

OpenAIのAgents APIやAnthropicのClaude Code / Coworkのように、AI企業がモデルより上のレイヤーへ進出すると、従来SIerが担っていた領域が狭くなる。

### Bull case

一方、大企業では、

- 既存基幹システム
- 社内規程
- 権限
- 監査
- データ品質
- 複数クラウド
- 部門間調整
- 業務固有の暗黙知

が残る。

モデルが高性能でも、これらは自動的には解決しない。

したがってフロンティアAIの進化は、NRIの仕事を消すだけでなく、**モダナイゼーション需要を急増させる**可能性もある。

## 5. 8月のNRI AFTは「モデル進化の速度」への回答にも見える

NRI AFTは8月3日開始。

時期としてはGPT-5.6世代の急速な性能・価格競争の中にある。

AFTでは、長期間の要件定義後に固定モデルを実装するのではなく、FDEが現場でROI検証を繰り返す。

### Interpretation

モデルが半年ごとではなく数週間〜数か月で更新される世界では、

> 設計時に決めたモデルを数年間固定する

というシステム開発は不合理になりやすい。

AFT型の高速反復は、**モデルの継続的な差し替え・評価を前提としたSIモデル**としても合理的である。

---

## 6. 9月時点で最も重要なのは「Agents API」型の潮流

GPT-6 Astraそのもの以上にNRIへ構造的な影響を与え得るのは、OpenAI等がエージェント開発基盤を直接提供すること。

モデルAPIだけなら、SIerが大きな統合レイヤーを持てる。

しかしAIベンダーが、

- エージェント実行
- ツール接続
- データ接続
- オーケストレーション
- 監視

まで標準化すると、SIerの付加価値領域は上流と顧客固有実装へ押し上げられる。

### Implication for NRI

NRI AFT、業界特化AI、顧客暗黙知の形式知化という2026年の動きは、この圧力に対する防御でもある。

---

## 7. GPT-6 Astra登場後の市場反応も無視できない

9月初旬には、GPT-6 Astraによるソフトウェア・SaaS代替懸念から日本のIT/SaaS関連株が売られる局面があり、NRI株も下落した。

個別企業要因と市場全体要因を分離する必要はあるが、これは投資家がAIをNRIにとって「成長機会」だけでなく「既存ITサービスを破壊するリスク」と見ていることを示す。

### Watch

今後、NRIが決算説明で以下をどう説明するかが重要。

- GPT-6等でAI駆動開発の生産性がさらに上がったか
- 生産性向上分を価格・利益・案件量のどこへ転換したか
- OpenAI / Anthropic等との競合と協業の境界
- AIエージェント基盤を自社開発するのか、外部基盤へ乗るのか

---

## 8. 現時点での判定

### 直接的な戦略変更

**確認できず。**

### 間接的な方向性

**整合性あり。**

8〜9月のモデル進化は、むしろNRIが2026年春から掲げている

- マルチモデル
- 業務別評価
- AX
- FDE
- AIネイティブ化
- セキュリティ / ガバナンス

の必要性を強めている。

ただし、AIベンダー側が企業システム統合まで急速に上がってくるため、NRIには「AIを導入できます」以上の価値証明が必要になる。
