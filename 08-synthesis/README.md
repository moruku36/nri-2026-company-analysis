## 一文でまとめると

**2026年のNRIは、高収益な国内SI/コンサル企業から、「AIを使って顧客企業と自社の両方を変革するAX企業」へ移行し始めた。戦略の方向性は整合的だが、AFT/FDE、AI駆動開発、AI関連売上を実際の利益・継続収益・顧客成果へ変換できるかは、まだ検証途上である。**

## 最重要テーマ

### 1. AIは新規事業ではなく、既存NRIモデルの再設計

NRIのAI戦略は、AIサービスを一つ追加する話ではない。

- コンサルティングの高速化
- 開発工程のAI化
- モダナイゼーション需要の獲得
- AIエージェントの実装
- セキュリティ/ガバナンス需要の獲得
- 人材の上流シフト
- 共同利用型/リカーリング型サービスへの転換

を同時に進める構造になっている。

### 2. 勝負は「モデル性能」ではなく「顧客コンテキスト」

OpenAI、Anthropic、Google等がモデル能力を急速に高める中で、NRIが守るべき価値は、

- 顧客固有の業務
- 暗黙知
- 規制・制度
- 既存システム
- データ
- セキュリティ
- 本番運用

を理解し、AIを安全に組み込む能力である。

### 3. 最大の問いは「生産性向上を利益へ残せるか」

AI駆動開発で工数が減っても、顧客から値下げを要求されれば利益率は上がらない。

NRIが狙うのは、工数削減分を

- 上流提案
- 追加案件
- アウトカム型契約
- 共通サービス化
- 高度人材への再配置

へ変換し、価値ベースの収益モデルへ移すこと。

### 4. AFT/FDEは必要条件だが、差別化そのものではない

2026年にはAccenture等も大規模FDE体制へ進出している。

したがってNRI AFTの価値は「FDEがいること」ではなく、**FDEが日本企業の業務・基幹系・運用・セキュリティをどこまで理解し、本番成果へつなげられるか**で決まる。

### 5. 海外は成長オプションから信頼回復フェーズへ

2026年3月期の海外減損を受け、新中計では海外の規模拡大より収益性改善を優先している。

今後は売上高より、

- 営業利益率
- リカーリング売上
- 追加減損の有無
- マネージドサービス化

を見る方が重要。

## このレポートの結論の使い方

この分析は、NRIの株式を推奨するものでも、会社の内部状況を断定するものでもない。

公開情報から、

- 会社が何を目指しているか
- その戦略がどこまで整合しているか
- 何が成功条件か
- 何が失敗の兆候か

を追跡可能な形に整理したものである。
