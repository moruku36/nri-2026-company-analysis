## この章の読み方

株価イベントについては、同日に複数の材料や市場全体の要因が存在するため、単純な因果関係を断定しない。

- **Fact**: 開示数値、終値、会社発表
- **Market reaction**: 発表前後に実際に観測された株価変化
- **Outside view**: 報道・アナリスト等の解釈
- **Interpretation**: それらを合わせた本レポートの分析

特にAI関連リリースについて、「発表したから株価が上がった／下がった」とは原則として扱わず、決算・ガイダンス・バリュエーションとの関係を優先して読む。
