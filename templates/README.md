# PowerPointスライド雛形

[company-analysis-slides-template.pptx](./company-analysis-slides-template.pptx) は、他社にも流用できる編集用の9枚構成です。PowerPointまたは互換ソフトで開き、`[ ]` 内の案内を置き換えてください。表・図形・テキストは編集可能です。

## スライド構成

1. 表紙
2. 要旨と本資料の見取り図
3. 外部環境と市場の変化
4. 事業ポートフォリオと収益構造
5. 経営戦略と価値創出の道筋
6. 業績推移と経営目標
7. 成長施策の実行計画
8. 主要リスクとモニタリング項目
9. 結論・次回までの確認事項
