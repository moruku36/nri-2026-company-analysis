# 06. External View / 外部評価

基準日: 2026-09-25

## 結論を先に

- **投資家・アナリストの基調評価は強気**。ただし高い期待が株価へ織り込まれており、好決算でもサプライズ不足なら大きく売られる。
- **人材市場でのブランドは非常に強い**。理系学生、東大・京大層、転職市場で継続的に上位へ出る。
- 社員口コミでは **待遇・20代成長環境・法令順守**が高評価。一方、残業時間は一般企業より重く、プロジェクト依存の負荷が弱点として残る。
- 技術発信はQiita等で非常に活発だが、公開情報上は社員発信が中心で、**外部開発者がNRI製品・OSSを自発的に語る“プロダクト企業型コミュニティ”は相対的に弱い**。
- AI/AXについては、AFT等の発表はITメディアにも取り上げられているものの、2026年9月時点では **第三者が成果・ROIを検証した事例はまだ乏しい**。外部評価は今後の実績待ち。

## 外部評価を一枚で見る

| 視点 | 現在の評価 | 主な理由 |
|---|---|---|
| 株式市場 | 強気だが高期待 | 高利益率・国内成長・AI期待・高バリュエーション |
| アナリスト | 強気優勢 | 目標株価は現値を上回る集計が多い |
| 報道 | 基本的に好意的/事実報道 | AI・DX・高収益を評価。一方、海外減損は明確な失点 |
| 社員 | 高評価だが高負荷 | 高待遇・成長機会 vs 長時間労働/案件依存 |
| 学生 | 非常に人気 | 高待遇、ブランド、コンサル×IT、安定性 |
| 技術者コミュニティ | 発信量は強い | Qiita等で多数の社員記事。ただし外部エコシステムは限定的 |
| 海外一般認知 | 国内より弱い | 日本ではトップブランド、海外ではAccenture/IBM等より知名度が低い |

## 読み方の注意

外部評価はデータの質が混在する。

- 株価・アナリスト集計：比較的定量的だが将来予測
- 報道：事実確認に有効だが論調は媒体依存
- 社員口コミ：大量データでも自己選択バイアスあり
- 就活ランキング：人気度であり会社の実力そのものではない
- note / Reddit等：個別体験・印象としてのみ利用

そのため、本章では **「第三者がそう評価している」ことと、「その評価が正しい」ことを分ける**。
